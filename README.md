# Portfolio — AI–Full Stack Developer

A dark, premium Next.js portfolio with glassmorphism, gradients, and scroll animations.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize your content

Edit **`src/data/portfolio.ts`** — all copy, links, projects, experience, and skills live in one file.

Replace **`public/resume.pdf`** with your real resume.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide icons

## Deploy

Deploy on [Vercel](https://vercel.com) — connect this repo and deploy with default settings.
